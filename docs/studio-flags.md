# Local faction identification

National SVG flags come from [lipis/flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3), under MIT; see flag-icons-LICENSE.txt. The game IDs England and Korea map to GB and KR. Ukraine is included for Classic.

Hezbollah is an organization, not a country. Its flag is used at thumbnail size solely for neutral identification in the **local, development-only** roster. Source: [Wikipedia file description](https://en.wikipedia.org/wiki/File:Flag_of_Hezbollah.svg), downloaded from https://upload.wikimedia.org/wikipedia/en/0/08/Flag_of_Hezbollah.svg on 2026-10-04. This is non-free artwork, not covered by the national flag collection's MIT license. It is not approved for public distribution. The entire flags module is imported only by the local Studio; do not migrate it to a public page or publish it with the game.

All flags are inline, so the Studio makes no flag requests to external servers. No EA assets are involved.

The public faction pages publish the national flags only, as static files in `public/faction-art/flags/` with the MIT licence beside them (see faction-art.md). The Hezbollah flag is excluded there and stays local to the Studio; the public pages draw an original emblem instead.
