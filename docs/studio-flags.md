# Local faction identification

National SVG flags come from [lipis/flag-icons v7.3.2](https://github.com/lipis/flag-icons/tree/v7.3.2/flags/4x3), under MIT; see flag-icons-LICENSE.txt. The game IDs England and Korea map to GB and KR. Ukraine is included for Classic.

Hezbollah is an organization, not a country. Its flag is used at thumbnail size solely for neutral identification in the **local, development-only** roster. Source: [Wikipedia file description](https://en.wikipedia.org/wiki/File:Flag_of_Hezbollah.svg), downloaded from https://upload.wikimedia.org/wikipedia/en/0/08/Flag_of_Hezbollah.svg on 2026-10-04. This is non-free artwork, not covered by the national flag collection's MIT license. The owner approved its public use on the website on 7 October 2026 (faction-art.md); it is not cleared for distribution with the game. The flags module itself is imported only by the local Studio; public pages use the exported files.

All flags are inline, so the Studio makes no flag requests to external servers. No EA assets are involved.

The public faction pages publish these flags as static files in `public/faction-art/flags/`: the national flags with the MIT licence beside them, and, since the owner's decision of 7 October 2026, the Hezbollah flag as well. Its non-free status and the known risks are recorded in faction-art.md.
